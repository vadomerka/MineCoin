### Мониторинг

```powershell
helm uninstall vm-single -n monitoring
```
```powershell
kubectl delete namespace monitoring
```

### Логирование

```powershell
kubectl delete -f k8s/logging/
```
```powershell
kubectl delete namespace logging --ignore-not-found
```

### Приложение

```powershell
kubectl delete namespace minecoin
```
